# Repository Contents

  ## Graph Creation Scripts
  - Python scripts for creating instance graphs based on the ontologies
  ## UC Input Data Public
  - Use Case Dataset – A real-world bridge dataset, including an instance graph applying both SPOT and SPOT-AM
  ## UC Spatial Graph Public
  - Resulting instance graph in Turtle format
  ## SPARQL queries 
  - Competency Questions of ontology and their results based on the use case dataset
